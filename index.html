About

I am Pradipti Singh, a driven Software Development Engineer in Test (SDET) with expertise in UI & API automation and growing proficiency in AI-enhanced testing strategies.

I design and build robust test automation frameworks using Selenium, TestNG, BDD Cucumber for UI automation and Playwright with TypeScript for modern, scalable end-to-end testing. I work with Playwright concepts such as Page Object Model (POM), fixtures, reusable test utilities, assertions, hooks, and data-driven testing.

For API validation, I work with Postman and RestAssured, covering API functional testing, request/response validation, authentication, and integration scenarios. My workflows integrate seamlessly with Jenkins, Docker and AWS for continuous quality delivery.

As the QA landscape evolves, I'm actively upskilling in AI technologies. I leverage tools like ChatGPT for intelligent test generation and debugging, GitHub Copilot for code suggestions, and AI Agent for exploring automated QA workflows. These tools help boost productivity, accelerate test development, and reduce manual overhead.
